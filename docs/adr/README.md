# Architecture Decision Records

An ADR records one significant decision: the context, what we chose, and the trade-offs. ADRs
are short (one page), numbered, and never edited after acceptance. To change a decision, write
a new ADR that supersedes the old one.

**To add one:** copy [0000-template.md](0000-template.md) to `NNNN-short-title.md` using the next
number, fill it in, and open a PR. Discussion happens in the PR.
